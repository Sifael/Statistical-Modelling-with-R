# Statistical-Modelling-with-R

This a repository for the Data Analytics Course that I was a teaching assistant for on Fall 2024. It explores the use of R programming for Data Analytics and Statistical Modelling. 

### Statistical Modelling with R

This is a collection of notes and implementation of the Data Analytics Course that I was a TA for at Constructor University. 
The material developed was intended for students to develop practical ways to implement machine learning algorithms using the R programming language

1. Introduction to Tidyverse
2. Data Processing and Transformation
3. Exploratory Data Analysis (EDA)
4. Linear Regression
5. K Nearest Neighbor Classifier
6. LDA and QDA Classifiers
7. Logistic Regression
8. Decision Trees - Regression and Classification
9. Emsemble Methods
10. Clustering
11. Dimensionality Reduction
12. Ridge Regression and Lasso Regression
